# Palim

One connection and sign-in. This package includes the authenticated MCP connection, editorial workflow and setup skill together. Do not install a separate skill or add another Palim server.

Connect to the endpoint in `.mcp.json` using the client's OAuth flow. Let the user enter their email code in the browser and review consent. Creating and downloading an edition needs no Kindle destination. Sending is a separate requested action, with a confirmed destination managed in the web workspace.

For ChatGPT connection instructions, supported Codex installation and current verification limits, see [the repository](https://github.com/timc0y/palim#connect-palim). Public directory publication and physical Kindle acceptance are separate gates. This package is not a public-directory listing.
