# Palim

Connect and sign in once. The agent reads get_guide, then creates an EPUB or forwards an existing EPUB/PDF unchanged.

This package contains the MCP connection, client metadata and branding. Complete the client’s browser OAuth flow; never paste codes or tokens into chat. Creating/downloading needs no Kindle setup. Sending remains a separate requested action to a selected saved Kindle address. Approve your account’s exact personal Palim sender once in Amazon.

See the [connection steps](https://github.com/timc0y/palim#connect-palim) and verification record. This is a repository package, not a public-directory listing.
