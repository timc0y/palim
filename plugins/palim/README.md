# Palim

One connection and sign-in. The agent reads the get_guide tool, then creates a reading edition or forwards an existing EPUB/PDF unchanged. No skill installation or setup hook is needed.

This package contains only the MCP connection, client metadata and branding. Complete the client’s browser OAuth flow; never paste codes or tokens into chat. Creating/downloading needs no Kindle setup. Sending remains a separate requested action to a confirmed destination.

See the [connection steps](https://github.com/timc0y/palim#connect-palim) and current verification limits. This is a repository package, not a public-directory listing or proof of authenticated client/Kindle acceptance.
