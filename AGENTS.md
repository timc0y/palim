# Working on Palim

Read `SIMPLE.md` first. Apply the shared Simple method when available. Preserve the two independent journeys: create a new illustrated book; forward an existing EPUB/PDF unchanged.

One integrator owns writes. Specialist reviewers are read-only unless assigned exclusive paths. Never commit credentials, private manuscripts, destinations, tokens, provider responses or other repositories' private content. No model inference in the publishing service.

Use maintained packages, bounded inputs, explicit ownership and honest receipts. Test the user-facing operation, not only a helper. Local code checks do not prove deployment, Cloudflare acceptance, Amazon import or physical Kindle behaviour. Record each separately in `docs/verification.md`.

Do not edit other projects or alter unrelated Cloudflare infrastructure. Public release must not advertise an unverified hosted service as working.
