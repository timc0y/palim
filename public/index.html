Two independent paths

Create an illustrated EPUB

Pass chapters in Markdown from an AI conversation or the web studio. Palim builds a valid, reflowable EPUB 3 with an automatic paper cover, table of contents, bounded Mermaid diagrams, labelled bar charts, PNG/JPEG figures, and source notes.

Deterministic packaging only — no language model runs inside Palim.

Forward an original unchanged

Upload an existing EPUB or PDF in the studio or pass one from your agent. Palim verifies bounded metadata and SHA-256 integrity, then emails the exact original bytes to your selected Kindle address.

No repair, recompression, watermark, or metadata rewrite.

Live specimen

One stop of light

A 510-word field guide to shutter speed and exposure, generated directly from a single JSON manuscript. Includes a rasterized bar chart, an aperture-exchange diagram, tabular settings, and source citations, validated in CI with EPUBCheck.

Chart values are calculated exposure ratios, not measured camera data. Browser previews test layout, not physical Kindle rendering.

Connect & use

Web Studio

Sign in with a six-digit email code — no password or Amazon credentials required. Draft multi-chapter Markdown books with # headings, drop an EPUB or PDF to send unchanged, preview files privately in the browser, and manage saved Kindle addresses.

Open studio

Any MCP client

Connect over OAuth at /mcp from ChatGPT or Codex, or generate a Personal MCP token in Settings → Agent for clients that take an Authorization: Bearer header. Seven focused tools handle guides, images, book creation, link recovery, destination labels, sending, and delivery receipts. Drafts never send mail.

Client setup steps ↗

Amazon setup once

Each account receives a unique personal sending address on the configured sending domain. Approve that exact address once in Amazon’s Personal Document Settings, then save up to five labelled Kindle addresses. Saving addresses sends no mail; every delivery requires an explicit request.

Honest limits & privacy

Licence
Free and MIT open source by Tim Coy. Independent software; not affiliated with Amazon or Kindle.
Retention
Books, uploads, manuscripts, and previews expire after 24 hours; signed links expire after 15 minutes; minimal delivery receipts stay 35 days.
Sizes & quotas
Uploads up to 20 MiB; Cloudflare Email limit 5 MiB encoded (larger files remain downloadable). Hosted defaults: 2 generated books, 6 uploads, and 3 email submissions per account per UTC day, with shared ceilings.
Receipts
submitted means Cloudflare accepted the email — never inferred as Amazon conversion, library import, or physical Kindle receipt.

Self-host on Cloudflare

Run your own private instance on a Cloudflare Workers Paid account using one Worker, D1, private R2, KV, outbound Email Sending, and a thin Pages front door. Try the local publisher without any cloud account or secrets: 

git clone https://github.com/timc0y/palim.git
cd palim && npm ci && npm run example
